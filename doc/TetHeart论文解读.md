# TetHeart 论文解读：End-to-End 4D Heart Mesh Recovery Across Full-Stack and Sparse Cardiac MRI

> **论文信息**
>
> - 标题：End-to-End 4D Heart Mesh Recovery Across Full-Stack and Sparse Cardiac MRI
> - 作者：Yihong Chen、Jiancheng Yang、Deniz Sayin Mercadier、Hieu Le、Juerg Schwitter、Pascal Fua
> - 机构：EPFL、ELLIS Institute Finland / Aalto University、UNC Charlotte、CHUV 介入 MRI 中心
> - 发表：TMLR 2026（arXiv:2509.12090，v3）
> - 代码与数据：<https://github.com/Scalsol/TetHeart>
>
> **一句话定位**：TetHeart 是首个统一的端到端 4D 心脏网格恢复框架，用同一套模型同时处理术前完整 CMR 堆栈和术中仅 1～5 张实时 2D 切片，在稀疏观测下直接重建左心室（LV）、右心室（RV）和心肌（MYO）的形状与运动。

---

## 1. 背景、研究目的与要解决的问题

### 1.1 研究背景

心脏的 4D（3D 形状 + 时间运动）建模对诊断、预后评估、手术规划和图像引导介入都有直接价值。心脏磁共振（CMR）能提供高软组织对比度的时序解剖信息，是当前最主要的成像来源。

但现有 4D 心脏重建方法几乎都建立在**完整 CMR 堆栈**之上：

- 采集一个完整 3D 堆栈需要逐层扫描，通常要 4～6 个心跳的屏气，耗时数分钟；
- 这只适合术前的离线分析和手术规划，无法用于手术进行中的实时场景。

在真实的介入 MRI（iCMR）场景中，例如电生理消融、心室心律失常消融，为了达到 20～25 Hz 的时间分辨率，MRI 只能在空间分辨率和扫描层数上做妥协：术中通常只能实时获得**少量（1～3 张）、低分辨率、位置任意、甚至与术前扫描角度不一致的 2D 切片**。作者在合作医院的实际设备上也观察到了这一限制。

因此，现有方法在术中会直接失效——它们要么要求完整体积输入，要么需要测试时优化，要么只能处理心肌单一结构，无法满足介入导航对速度、稀疏输入和全心脏结构的要求。

### 1.2 要解决的核心问题

**如何仅凭术中实时获取的极稀疏 2D 切片（少至 1 张），恢复患者特异性的、覆盖 LV/RV/MYO 的完整 3D 心脏形状与逐帧运动？**

具体难点包括：

1. **输入稀疏且任意**：切片的数量、层厚、位置、角度都不固定，传统 3D CNN 或固定网格方法难以直接处理；
2. **术前与术中数据不一致**：术中切片可能来自不同序列、不同扫描角度，与术前完整堆栈存在域差异；
3. **标注昂贵**：公开数据集通常只在 ED（舒张末）和 ES（收缩末）两个关键帧提供分割/网格标注，缺少逐帧真值，无法做全监督运动学习；
4. **实时性**：介入导航要求前向推理足够快，不能依赖 4DMR 这类测试时逐例优化；
5. **全心脏结构**：不能只重建心肌，还需要同时保持 LV、RV 的解剖一致性。

### 1.3 研究目标

构建一个**统一的端到端框架**：

- 术前用高质量完整堆栈初始化患者特异性的详细心脏网格；
- 术中用任意数量、任意位置的实时切片持续更新该网格，最少可只用一个切片；
- 不做测试时优化、不需要推理时的真值轮廓/分割，直接从前向网络输出 4D 网格；
- 一个模型同时覆盖离线 full-stack 与在线 sparse-slice 两种模式，并具备跨数据集、跨中心的零样本泛化能力。

## 2. 核心创新点

### 2.1 首个统一 full-stack / sparse-slice 的端到端 4D 心脏网格框架

在此之前，离线完整堆栈重建和术中稀疏切片重建是两套问题、两类方法。TetHeart 用**同一个网络、同一套权重**统一了两种输入模式，并且从完整堆栈到单张切片都能工作。这使心脏建模从“回顾性分析”向“术中实时应用”推进了一步。

### 2.2 基于可变形四面体的统一形状–运动表示

论文采用 **Deep Marching Tetrahedra（DMTet）** 作为心脏表示：

- 用可变形四面体网格 \(\mathcal{G}=(\{v_i\},\{s_i\},\mathcal{T})\) 表示心脏，每个顶点带一个 SDF 值，表面通过可微 marching tetrahedra 提取；
- 初始帧重建得到 \(\mathcal{G}^0\)，后续帧只更新顶点位置、保持 SDF 与拓扑不变，即 \(v_i^t=\mathcal{D}(v_i^0,\mathbf{O}^t)\)；
- 四面体空间为 LV/RV/MYO 提供了一个**共享的、显式–隐式混合的连贯空间**，既保留 SDF 的优化效率，又有网格的几何灵活性。

相比纯网格（MeshDeformNet）或纯 SDF（DeepCSR）变体，这种表示在稀疏输入下更能保持空间连贯性，是性能提升的重要来源。

### 2.3 Attentive 2D–3D Feature Assembler（AFA）：切片自适应特征聚合

AFA 解决“任意数量、任意位置切片 → 统一 3D 体积特征”的问题：

- 利用 DICOM 头信息把每张 2D 切片放到术前体积的精确 3D 坐标上，建立 2D 像素到 3D 位置的对应；
- 对 3D 特征图中的每个体素，先选空间上最近的 \(k_1=3\) 张切片，再在每张切片内选最近的 \(k_2=9\) 个位置作为 key/value，只做局部 multi-head attention；
- 这种受 Swin Transformer 启发的局部注意力，计算复杂度约等于一个 \(3\times3\times3\) 的 3D 卷积，但能灵活适应切片数量与位置变化；
- 同一模块既可用于**静态重建**（\(F^0_{2d}\) 对自身做 self-attention），也可用于**运动估计**（以初始帧特征为 query、目标帧切片特征为 key/value 做 cross-attention）；
- 静态分支和运动分支共享 2D 编码器与 3D 卷积，使运动估计能复用静态重建学到的 3D 解剖知识。

### 2.4 Full-to-sparse 蒸馏：用完整堆栈教稀疏输入

训练时对同一目标帧构造两个输入：

- 教师：完整切片堆栈 \(\mathbf{I}^l\)，得到 \(V^l_{\text{motion}}\)；
- 学生：随机采样 1～D 张切片并施加下采样、旋转、噪声等退化，得到 \(\hat{V}^l_{\text{motion}}\)。

用 stop-gradient 的 L2 蒸馏损失 \(\|\hat{V}^l_{\text{motion}}-\text{sg}(V^l_{\text{motion}})\|_2\) 把完整输入的特征迁移到稀疏输入，使模型在极端稀疏下仍能保持准确重建。

### 2.5 仅需关键帧标注的两阶段弱监督运动学习

公开数据通常只有 ED/ES 的标注，论文因此设计了两阶段训练：

1. **第一阶段：训练静态重建分支**。在带标注的 ED/ES 帧上，用 Chamfer 距离、SDF L1 损失和分割交叉熵训练，得到从图像预测四面体网格的能力；
2. **第二阶段：训练运动分支**。对一条序列随机取一个无标注帧和一个有标注帧：先用已训练的静态分支从无标注帧预测 \(\mathcal{G}^u\)，再把有标注帧随机抽成 1～D 张切片并做退化增强，预测从 \(u\) 到 \(l\) 的变形；损失为 full-slice 与 few-slice 两条路径的 Chamfer 距离加上蒸馏损失。

这样无需逐帧真值，也能学习连续运动；且训练后模型可以从任意相位开始预测形变，而不只是从 ED 开始。

## 3. 主要研究方法

### 3.1 问题形式化

给定初始帧 \(\mathbf{I}^0\in\mathbb{R}^{D\times H\times W}\) 重建的网格 \(\mathcal{G}^0\)，以及后续时刻的观测 \(\mathbf{O}^t\)，目标是估计形变后的网格：

\[
\mathcal{G}^t=(\{v_i^t\},\{s_i\},\mathcal{T}),\qquad v_i^t=\mathcal{D}(v_i^0,\mathbf{O}^t)
\]

- **Offline 模式**：\(\mathbf{O}^t\) 与 \(\mathbf{I}^0\) 同为完整体积；
- **Online 模式**：\(\mathbf{I}^0\) 是术前完整堆栈，\(\mathbf{O}^t\) 是术中 1～3 张任意位置的低分辨率 2D 切片。

### 3.2 网络流程

1. **2D 编码**：每张切片先经过 2D 编码器提取特征 \(F^0_{2d}\)、\(F^t_{2d}\)；
2. **AFA 聚合**：静态分支做 self-attention 得到 \(V^0_{\text{static}}\)；运动分支以初始帧特征为 query、目标帧切片为 key/value 得到 \(V^t_{\text{motion}}\)；
3. **3D U-Net 编码**：两个分支共享后续 3D 卷积，输出 \(F^0_{\text{static}}\)、\(F^t_{\text{motion}}\)；
4. **初始网格重建**：从单位立方体均匀采样四面体网格 \(\mathcal{G}^{init}\)，三线性插值静态特征，用 GCN 预测每个顶点的 SDF 和位置偏移，得到 \(\mathcal{G}^0\)；
5. **运动恢复**：在顶点处插值并拼接静态/运动特征，经 GCN + GRU + MLP 迭代两次更新顶点位置，得到 \(\mathcal{G}^t\)；
6. **表面提取**：通过可微 marching tetrahedra 得到显式心脏表面网格。

### 3.3 损失函数

**静态重建阶段：**

\[
\mathcal{L}_{shape}=\lambda_{cd}\mathcal{L}_{cd}(\text{MT}(\mathcal{G}^p),\mathcal{M}^{gt})
+\lambda_{sdf}\mathcal{L}_{sdf}(\mathcal{G}^p,\mathcal{M}^{gt})
+\lambda_{ce}\mathcal{L}_{ce}(L^p,L^{gt})
\]

其中 \(\lambda_{cd}=1.0,\lambda_{sdf}=0.1,\lambda_{ce}=0.1\)，分别约束 Chamfer 距离、顶点 SDF 与分割结果。

**运动阶段：**

\[
\mathcal{L}_{motion}=\mathcal{L}_{distill}(V^l_{\text{motion}},\hat{V}^l_{\text{motion}})
+\mathcal{L}_{cd}(\text{MT}(\mathcal{G}^{u\rightarrow l}),\mathcal{M}^l)
+\mathcal{L}_{cd}(\text{MT}(\hat{\mathcal{G}}^{u\rightarrow l}),\mathcal{M}^l)
\]

### 3.4 实验设置

- **训练数据**：ACDC（约 100 例）、M&Ms（375 例）、M&Ms-2（360 例）构成统一数据集，共 **835 条 CMR 序列**；按受试者级别 60%/20%/20% 划分训练/验证/测试，避免数据泄漏。
- **外部零样本评测**：
  - **iCMR**：合作医院介入 MRI 系统采集，包含静息与轻度运动负荷下的单层中部切片，模拟术中实时场景；
  - **4DM**：提供逐帧心肌网格标注，用于评估全序列运动重建和弱监督方案。
- **指标**：3D Chamfer Distance（CD，越小越好）、切片 Dice（越大越好）、LV/RV 收缩末容积（ESV）与射血分数（EF）的 MAE、全局纵向应变（GLS）MAE。
- **对比方法**：4DMR、MR-Net、MulViMotion、DeepMesh，以及 FFD、dDemons 等传统配准方法；另设 MeshDeformNet（Ours-Mesh）和 DeepCSR（Ours-SDF）两个只替换形状表示的消融变体。
- **实现**：切片重采样到 \(1.25\times1.25\) mm，AFA 构造有效间距 \(1.25\times1.25\times2\) mm 的体积；SGD，学习率 0.01，重建/运动阶段分别训练 300/150 epoch；单张 V100 完成。

## 4. 主要发现与结论

### 4.1 稀疏切片运动估计显著优于现有方法

从 ED 形变到 ES，仅用 **1 张中心切片**时（CD，mm²，越小越好）：

| 数据集 | 最优对比方法（MYO CD） | 本文 TetHeart（MYO CD） |
|---|---|---|
| ACDC | DeepMesh 27.47 | **15.24** |
| M&Ms | DeepMesh 14.29 | **9.76** |
| M&Ms-2 | DeepMesh 15.35（4DMR 15.52） | **10.12** |

仅用 **5 张切片**时，M&Ms 心肌 CD 降至 **7.93**（DeepMesh 11.19），ACDC 为 **10.22**（MR-Net 18.82）。切片越少，TetHeart 相对其他方法的优势越大。

在临床指标上（M&Ms，1-slice）：

- LVEF MAE **4.83%**（MR-Net 7.87%）；
- LVESV MAE **7.51 ml**（MR-Net 9.76 ml）；
- RVEF MAE **8.51%**（MR-Net 11.75%）；
- 单切片条件下仍能给出有生理意义的容积与射血分数。

### 4.2 完整堆栈场景同样达到 SOTA

即使论文的主要动机是稀疏输入，使用完整堆栈时仍全面领先：

| 数据集 | 心肌 CD（全堆栈） | 最优对比方法 |
|---|---|---|
| ACDC | **6.63** | MR-Net 14.02 |
| M&Ms | **4.11** | MR-Net 8.86 |
| M&Ms-2 | **4.02** | MR-Net 8.39 |

全堆栈下 LVEF MAE 为 **2.04%**、LVESV MAE **4.84 ml**、RVEF MAE **4.77%**、RVESV MAE **9.65 ml**，优于 MR-Net 及传统 FFD/dDemons。作者认为原因包括：直接建模网格而非“先分割再变形”减少误差累积；静态与运动分支共享编码器；AFA 能动态聚合空间相邻特征。

### 4.3 零样本泛化能力强

**iCMR 私有介入数据集（不重新训练）：**

- 在三个公开数据集上训练后，TetHeart 的 Dice 为 MYO **80.15%**、LV **83.22%**、RV **79.76%**；
- 4DMR 仅为 MYO 71.33%，MR-Net 为 76.11%/78.65%/72.11%；
- 能处理静息与运动负荷下心率变化，预测的容积–时间曲线符合生理规律（运动时收缩末到舒张末恢复期缩短、心动周期变短）。

**4DM 数据集（逐帧心肌标注，零样本）：**

| 设置 | TetHeart | MR-Net | 提升 |
|---|---|---|---|
| 1-slice | **11.33** | 15.87 | 约 29% |
| 5-slice | **9.08** | 11.56 | 约 21% |
| Full-slice | **5.51** | 7.97 | 约 31% |

在 4DM 上直接训练并评测的 Oracle 为 6.24/4.87/2.70（依次对应 1-slice/5-slice/full-slice），说明零样本结果已接近但仍有差距。

**应变分析**：1-slice 下全局纵向应变 MAE 为 **2.18%**，优于 MR-Net 的 3.73%、4DMR 的 4.47%，从运动学角度验证了预测的合理性。

### 4.4 消融实验确认各模块作用

在 M&Ms 心肌 CD 上：

| 配置 | 1-slice | 5-slice | Full-slice |
|---|---|---|---|
| 完整模型 | **9.76** | **7.93** | 4.11 |
| 去掉 AFA | 不支持变长输入 | 不支持变长输入 | 4.22 |
| 去掉位置编码 | 11.23 | 9.04 | 4.67 |
| query 中去掉图像特征 | 16.67 | 12.37 | 6.44 |
| 不共享编码网络 | 20.66 | 11.63 | 6.43 |
| 去掉蒸馏损失 | 10.34 | 8.12 | 4.03 |

结论：

- AFA 是处理任意切片数量/位置的关键，缺失时只能退回固定 full-slice 输入；
- 位置编码和图像特征缺一不可，只保留位置编码会大幅退化；
- 共享静态/运动编码器带来最大的稀疏场景收益；
- 蒸馏损失略微牺牲 full-slice 性能，但显著提升 1/5-slice 鲁棒性；
- 加入介入伪影模拟增强后，1-slice 心肌 CD 从 14.45 降到 10.98，说明退化增强对术中域偏移很重要。

### 4.5 效率

- 推理速度 **12 FPS**（V100），无需测试时优化；
- 模型约 **23M** 参数，与最强对比方法 MR-Net（22M）相当，但精度更高；
- 作者指出可进一步通过量化或轻量编码器满足更严格的实时约束。

### 4.6 总体结论

1. 首次证明**从稀疏术中 CMR 数据推断准确 3D 心脏运动是可行的**；
2. 一个模型可以同时覆盖术前 full-stack 与术中 sparse-slice，且均达到 SOTA；
3. 可变形四面体 + AFA + 蒸馏 + 关键帧弱监督的组合，能在极少标注、极少切片条件下保持解剖连贯性和生理合理性；
4. 为患者特异性“跳动心脏数字孪生”和实时图像引导介入奠定了基础。

## 5. 对领域的贡献

1. **问题定义与范式贡献**：把“术中稀疏切片 4D 心脏重建”从不可解问题变成可评测、可复现的研究任务，并给出统一 offline/online 的建模范式。
2. **表示贡献**：将 DMTet 可变形四面体引入 4D 心脏形状–运动联合建模，为多结构（LV/RV/MYO）提供共享的连贯空间，避免了“先分割/提轮廓再变形”的两阶段误差累积。
3. **方法贡献**：提出 AFA 切片自适应 2D–3D 特征聚合，使网络能处理任意数量、任意空间位置的切片；其局部注意力设计在保持效率的同时获得接近 3D 卷积的开销。
4. **训练策略贡献**：full-to-sparse 蒸馏 + 两阶段关键帧弱监督，使模型只需 ED/ES 标注即可学习逐帧运动，大幅降低数据标注门槛，并提升极端稀疏下的稳定性。
5. **实验与临床贡献**：在 835 条序列上训练，在私有 iCMR 和公开 4DM 上零样本验证，提供了介入场景下可用的精度、速度与生理指标证据；代码和数据开源，推动可复现研究。
6. **应用前景**：为 iCMR 引导的射频消融、器械定位、实时心脏导航提供“少量切片 → 全心脏动态网格”的技术路径。

## 6. 局限与不足

### 6.1 稀疏与完整输入之间仍有性能差距

单切片/5 切片的重建误差明显高于完整堆栈（如 M&Ms 心肌 CD：9.76 / 7.93 vs 4.11）。作者计划引入**物理约束**（如心肌近似不可压）或**生成式模型**逐步生成网格序列来缩小差距，但需要在速度与质量之间权衡。

### 6.2 蒸馏可能带来“平均化解剖”和幻觉

蒸馏损失会把群体统计知识注入稀疏分支，可能生成带有平均特征的心脏形状，**掩盖个体特有的病理异常**。虽然可以通过术中动态调整扫描平面补充信息来缓解，但论文尚未实现专门的时间模块来充分利用这些信息。

### 6.3 缺少显式时序建模

当前运动恢复主要是逐目标帧的前向变形，没有专门的时序模块（如时序 Transformer/状态空间模型）来显式利用帧间连续性；GRU 只在顶点变形迭代内使用，并非跨帧记忆。

### 6.4 拓扑固定，表达力有限

方法保持初始网格的 SDF 与拓扑不变，只变形顶点。这对于心脏周期内的形变够用，但难以处理拓扑变化、组织撕裂、消融损伤等介入相关现象，也没有建模心肌材料属性或电生理耦合。

### 6.5 临床验证仍不充分

- iCMR 数据规模有限，主要来自单一合作医院和特定扫描协议；
- 只在短轴（SAX）视图上验证，长轴、任意斜切面、不同厂商设备的表现仍待评估；
- 零样本结果与 Oracle 仍有明显差距，域偏移（不同医院、不同序列、不同病理）下的鲁棒性需要更大规模多中心验证；
- 作者明确说明当前定位是**辅助工具**，不能替代临床医生审核；对罕见解剖、低质量采集、分布外病例存在错误风险，需要不确定性估计和质量控制。

### 6.6 实时性仍可提升

12 FPS 在 V100 上尚不能完全满足最严格的介入实时要求（尤其多结构高分辨率场景），且未报告端到端（含预处理、后处理、可视化）延迟；模型量化、轻量编码器、TensorRT 部署等仍是工程化待办。

### 6.7 评测指标的局限

Chamfer Distance 和 Dice 衡量几何/切片重叠，不能完全反映心肌应变、纤维方向、局部收缩功能等临床关心的运动学特性；论文只补充了全局纵向应变，局部应变和跨结构一致性评估仍有限。

---

## 7. 一句话总结

**TetHeart 用可变形四面体把术前完整 CMR 与术中极稀疏实时切片统一到同一个端到端 4D 心脏网格重建框架中，通过切片自适应 2D–3D 注意力、full-to-sparse 蒸馏和仅关键帧标注的弱监督运动学习，首次实现了从单张切片到全心脏动态网格的准确、快速、可泛化恢复，为实时图像引导心脏介入铺平了道路。**
