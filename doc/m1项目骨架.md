# 模块 M1 接口契约：项目骨架

## 1. 目标（一句话）
搭好 FastAPI 项目骨架：能启动、有配置管理、有健康检查。后面 11 个模块全部挂在这个骨架上。

## 2. 目录结构（照抄这个，一个文件都不能少）
askbot/                          # 项目根目录（Windows 路径下建）
├── app/
│   ├── __init__.py              # 空文件
│   ├── main.py                  # FastAPI 入口：创建 app、挂路由
│   ├── core/
│   │   ├── __init__.py          # 空文件
│   │   └── config.py            # Settings 类（pydantic-settings，读 .env）
│   └── api/
│       ├── __init__.py          # 空文件
│       └── v1/
│           ├── __init__.py      # 空文件
│           └── health.py        # GET /healthz 路由
├── tests/
│   ├── __init__.py              # 空文件
│   └── test_health.py           # 测 /healthz
├── .env.example                 # 配置模板（提交 git）
├── .env                         # 真实配置（不提交 git）
├── .gitignore
├── requirements.txt
└── README.md                    # 先写项目名+一句话就行


① 建环境
python -m venv .venv
.venv\Scripts\activate        （Windows 激活）
pip install fastapi "uvicorn [standard]" pydantic-settings pytest httpx
验证：pip list 里能看到 fastapi

② 最小应用
写一个 app/main.py：FastAPI () 实例 + GET /ping 返回 {"pong": True}
验证：uvicorn 启动后，浏览器打开 [http://127.0.0.1:8000/ping](http://127.0.0.1:8000/ping) 看到 JSON

③ 配置
在 app/core/config.py 写 Settings 类：app_name="askbot"、app_version="0.1.0"
验证：打印 settings.app_name 输出 askbot；建 .env 改 app_name 后能读到新值

④ 路由拆分（第一次体验 "分层"）
在 app/api/v1/health.py 用 APIRouter 定义 GET /healthz，
返回 status/version (来自 settings)/time (UTC 当前时间)，
在 main.py 里 include_router 挂上
验证：curl [http://127.0.0.1:8000/healthz](http://127.0.0.1:8000/healthz) 返回三个字段的 JSON

⑤ 测试
在 tests/test_health.py 用 TestClient 测：/healthz 返回 200 且 json ()["status"]=="ok"
验证：pytest 全绿（注意：TestClient 需要先装了 httpx）

⑥ 收尾
建齐契约第 2 节的全部目录和空文件；写 requirements.txt、.gitignore
（.venv/、**pycache**/、.env 必须忽略）；git init
验证：git status 里看不到 .venv 和 .env

⑦ 全量验收
按契约第 4 节逐条打勾，特别是 "改 version 重启后生效" 那条
验证：8 个勾全打上 = M1 完成
