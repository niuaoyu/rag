# 模块 M3 接口契约：文档上传

## 1. 目标（一句话）
登录用户上传 PDF/文本 → 文件安全落盘 + documents 表记录（status=pending）→ 能查自己的文档列表和详情。
解析/切块是 M4 的事，M3 不做。

## 2. 目录增量（M2 基础上新增）
app/
├── models/document.py        # Document 模型（第一次写外键）
├── schemas/document.py       # DocumentOut
├── services/storage.py       # ★ 校验+落盘+建记录（你第一个 service 层）
└── api/v1/documents.py       # 上传/列表/详情路由
uploads/                      # 文件存储目录（记得加进 .gitignore）
tests/test_documents.py

## 3. 数据模型
documents 表：
- id: int, PK, 自增
- user_id: int, FK → users.id, not null, index   # 归属：只能看自己的
- filename: str(255), not null                   # 原始文件名（仅展示用）
- stored_path: str(255), not null                # 落盘路径 uploads/{user_id}/{uuid}.{ext}
- size: int, not null                            # 字节数
- status: str(16), default "pending"             # M4 做流转，M3 只保证初始值
- created_at: datetime, server_default now()

## 4. API 契约
POST /api/v1/documents          # multipart/form-data，字段名 file，需鉴权
  响应 201: {"id":1,"filename":"a.pdf","status":"pending","size":12345,"created_at":"..."}
  错误: 401 未登录 / 415 非 pdf/txt/md / 413 超 10MB / 422 缺 file 字段

GET /api/v1/documents           # 需鉴权
  响应 200: [...]  # 只含当前用户的文档，按 id 倒序

GET /api/v1/documents/{id}      # 需鉴权
  响应 200: {"id":1,"filename":"a.pdf","status":"pending","size":12345,"created_at":"..."}
  错误: 401 / 404（不存在或不属于当前用户，统一 404，不泄露存在性）

## 5. 验收标准（DoD）
- [ ] documents 表含 user_id 外键
- [ ] 上传 .pdf → 201，且 uploads/{user_id}/ 下真实存在 uuid 命名的文件
- [ ] 未登录上传 → 401
- [ ] 上传 .exe → 415；>10MB → 413
- [ ] 文件名含 ../ 或中文 → 正常落盘（uuid 重命名，不直接用用户文件名）
- [ ] 造两个用户：互相看不到对方文档（隔离验证）
- [ ] GET /documents/{别人的id} → 404
- [ ] pytest ≥5 个测试全绿
- [ ] v2 方法三件套：报错先猜 3 原因 / 三问复盘写进 doc/m3文档上传.md / 合上代码重写 save_upload

## 6. 技术约束
- 新依赖：python-multipart
- 存储：本地 uploads/，按用户分目录；文件名用 uuid4 重命名，原始名只存库
- 大小 10MB；类型白名单 pdf/txt/md（扩展名判断，MVP 够用）
- ★ 校验+落盘+建记录必须放 services/storage.py，路由只做 HTTP 编排（≤20 行）
- 禁止用现成上传库

```bash

# 注册用户 A
curl -X POST http://127.0.0.1:8000/api/v1/users/register \
  -H "Content-Type: application/json" \
  -d '{"email": "a@test.com", "password": "password123"}'

# 注册用户 B
curl -X POST http://127.0.0.1:8000/api/v1/users/register \
  -H "Content-Type: application/json" \
  -d '{"email": "b@test.com", "password": "password123"}'

# 创建a 拿到token
TOKEN_A=$(curl -s -X POST http://127.0.0.1:8000/api/v1/users/login \
  -H "Content-Type: application/json" \
  -d '{"email": "a@test.com", "password": "password123"}' \
  | python -c "import sys,json;print(json.load(sys.stdin)['access_token'])")

# 创建b 拿到token
TOKEN_B=$(curl -s -X POST http://127.0.0.1:8000/api/v1/users/login \
  -H "Content-Type: application/json" \
  -d '{"email": "b@test.com", "password": "password123"}' \
  | python -c "import sys,json;print(json.load(sys.stdin)['access_token'])")

# 上传文档到a
echo "doc1" > /tmp/a1.txt
echo "doc2" > /tmp/a2.txt

curl -X POST http://127.0.0.1:8000/api/v1/documents \
  -H "Authorization: Bearer $TOKEN_A" \
  -F "file=@/tmp/a1.txt"

  -H "Authorization: Bearer $TOKEN_A" \
  -F "file=@/tmp/a2.txt"

# 查看a的文档的id
curl -s http://127.0.0.1:8000/api/v1/documents/list_documents \
  -H "Authorization: Bearer $TOKEN_A"

#假设a 文档id是1,2 有结果200

  -H "Authorization: Bearer $TOKEN_A"
```
