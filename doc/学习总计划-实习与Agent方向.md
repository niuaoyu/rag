## 3. 统一训练格式（每块 ≤1h，必须先看到结果）

### 3.1 任务块模板（贴到你的笔记里，逐块填）
```text
任务：<动词 + 产物>，例如"实现 process_document：txt→text 落库"
终点判定：<跑什么命令/看什么输出就算过>
AI 级别：L0/L1/L2/L3/L4/L5
DoD：<≥2 条可观测断言，必须是命令或字段，不是"我理解了">
验证命令：<可直接复制的命令>
交接动作：<3-10 分钟，见 3.3>
卡点：<具体失败点，含报错第一行>
感受：<一句话，允许是情绪>
下次待验证问题：<一个能用是/否回答的问题>
```

### 3.2 AI 辅助级别（你原文的 L2/L3 混了，这里归一化，直接照用）
| 级别 | AI 给什么 | 用在哪 | 频率限制 |
|---|---|---|---|
| L0 | 完整实现，你运行 + 复述结构 | 全新概念第一次（如 `BackgroundTasks`） | 每个新概念 ≤1 次，**禁止连续两块 L0** |
| L1 | 删掉 10-30% 关键行，你补 TODO | 已见过一次的同类功能（如第二个后台任务） | — |
| L2 | 只给函数签名 + 关键 API + 伪代码（**默认档**） | 常规推进 | — |
| L3 | 只给需求 + DoD，可查官方文档，不许索要完整答案 | 你已能写同类代码 | — |
| L4 | 限时 45 分钟独立实现核心，AI 只回答"是/否"式确认 | 面试模拟 | 每周 ≥1 次 |
| L5 | 改需求 / 埋 bug / 加约束，你必须解释 trade-off | 面试前 2 周 | 每周 ≥1 次 |

升降规则（针对你的"人格审判"倾向，写死）：
- 同一级别**连续 2 块一次过** → 升一级。
- 同一块**失败 ≥2 次** → **降半级**（L2→L1.5：AI 多给一个关键函数签名），不许加训、不许"发狠"。
- 评价对象永远是**这一块**，不是"我";写复盘时禁止出现"我太笨/我不行/我自制力差"。

### 3.3 交接动作（你的第 4 条漏洞：AI 停 → 休息 → 漂移）
新条件反射：**"AI 停止输出" = "轮到我输出"**。AI 说完最后一句后的 **3 分钟内**必须完成下面任意一项，**做完才允许休息/碰手机**：
1. 写 5 行伪代码（不看 AI 的输出）；
2. 录 60 秒语音复述 3 个关键点（回放一遍，挑 1 个说不清的点）；
3. 先预测运行结果 → 再跑 → 对比差异写 1 行；
4. 画一次状态流转（如 pending→processing→done/failed）；
5. 补 3 个 TODO 并写出各自的验收点；
6. 关掉资料写 input / method / output 三行；
7. 回答 1 道场景题（"进程崩了，processing 卡住怎么办"）。
> 物理保护：把手机放到另一个房间 + 计时器 3 分钟。这不是意志力问题，是把"交接"变成不可跳过的一步。

### 3.4 标准反馈格式（每次回给我 ≤10 行，先填前三行再谈感受）
