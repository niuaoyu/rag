# 面试拷打题（按模块，含答题抓手）

> 用法：每题先自己答，再对照抓手；答不上就回代码里找答案，别背。

## 用户与安全（M2）
1. 为什么 bcrypt 而不是 md5/sha256+盐？→ bcrypt 内置盐+慢函数+可调 cost，抗 GPU 暴力；md5 已碰撞、sha 太快。
2. JWT 注销怎么做？没有吊销列表的 JWT 有什么问题？→ 短过期+refresh / 黑名单 / 版本号；JWT 无状态即无法主动失效的代价。
3. 并发注册同一用户名，两个请求都查到"不存在"怎么办？→ 唯一索引兜底 + IntegrityError 捕获转 409（本项目有唯一索引，思考竞态窗口）。
4. JWT secret 泄漏了怎么办？→ 全部 token 作废需换 secret + 缩短过期 + 密钥轮换设计。
5. 密码策略为什么 max_length=128？→ bcrypt 72 字节上限；过长无意义还可能 DoS 哈希函数。

## 上传与异步（M3/M4）
6. 为什么上传接口返回 202 而不是 200/201？→ 语义：已受理、处理未完成；配套状态轮询。
7. BackgroundTasks 和 Celery 的取舍？什么信号说明该上 Celery？→ 任务时长/失败重试/多机扩展；本任务秒级且单机。
8. 后台任务为什么要自己开 DB session？→ 请求级 session 生命周期到响应即止；线程里用它=用已关闭的连接。
9. 状态机为什么落库而不是内存？→ 进程重启可恢复、失败原因可见、前端可轮询。
10. 上传的文件名能信任吗？→ `Path(name).name` 去目录 + uuid 前缀防覆盖/穿越；白名单后缀。
11. 重复上传同一文件怎么办（去重）？→ 现状允许重复；可加内容 hash 去重，讨论幂等。

## 切块与嵌入（M5/M6）
12. chunk_size 怎么定？太大/太小各有什么问题？→ 太大稀释主题+检索粒度粗；太小上下文断裂；800/120 是折中，理想按 token。
13. 为什么切块要带页码？→ 引用溯源粒度到页，面试演示加分项。
14. 向量为什么存 JSON 列而不是 blob？→ 调试可读、跨库可迁移；代价是体积与解析开销。
15. hash 嵌入的原理与天花板？→ n-gram 符号哈希=词面相似；无同义改写能力；诚实说出不冒充语义向量。
16. embedding 维度 256 够吗？→ 权衡存储/精度；真实模型 1536 起步，接口已参数化。

## 检索与 Agent（M7/M8/M9）
17. 为什么检索在生成前固定做，而不是让模型自己决定查不查？→ RAG 主链路确定性优先；也讨论 agentic RAG 的取舍。
18. tool_call 的消息协议长什么样？→ assistant(content=null,tool_calls) → tool(tool_call_id,result) → assistant 收口；ID 对齐是关键。
19. 模型反复调用工具不收敛怎么办？→ 轮次预算 + 预算耗尽去 tools 强制收口（有测试）。
20. SSE 和 WebSocket 怎么选？→ 单向服务端推送 SSE 够用；HTTP 语义/自动重连/代理友好；双向才 WebSocket。
21. 流式期间 DB session 的坑？→ 请求级依赖的 session 在响应头返回后关闭；生成器自管 SessionLocal（本项目真实踩过）。
22. TTFT 怎么算？怎么降？→ 首 delta 时刻-请求时刻；实测 0.70s；降法：引用先行/更短 system/网关就近。
23. 引用怎么防幻觉（模型编页码）？→ 引用由检索层生成（不是模型生成）随 citations 下发，模型只负责标号。
24. 多轮上下文为什么只取 6 条？→ token 预算与相关性的折中；讨论摘要压缩。

## 工程与部署（M10/M11）
25. 统一错误为什么要接管 starlette 的 HTTPException？→ 404/405 路由错误走 starlette 类，只注册 fastapi 的接不住（真实踩过）。
26. 500 响应里该不该有异常详情？→ 不该；日志有、响应只有 code；有测试断言。
27. Dockerfile 里 pip 层缓存怎么利用？→ 先 COPY requirements 再 COPY 代码；改代码不重装依赖。
28. healthcheck 的 start-period 干嘛的？→ 应用启动期不计失败次数。
29. compose 里 environment 和 env-file 的优先级？→ environment 显式覆盖；`${VAR:-default}` 默认值语义。
30. SQLite 在什么规模必须换 Postgres？→ 多实例/并发写/连接数；接口层已隔离 ORM。
31. pytest 怎么做到不联网？→ conftest 最先设 `LLM_PROVIDER=mock` 等环境变量再 import app；依赖注入可替换。
32. 访问日志中间件为什么用 try/finally？→ 异常路径也要记录；异常继续向上交给错误中间件。

## 复盘与产品（M12）
33. 这个项目最难的 bug？→ 流式+自管 session / 推理网关空 content（都能讲出"现象→定位→修复→测试"四段）。
34. 如果用户量 ×100，第一个崩的是什么？→ SQLite 写锁与全量向量内存检索；给出迁移顺序。
35. 怎么评估检索质量？→ 标注 Q-D 对，算 hit@k/MRR；警惕用词面向量自测的"虚高"（诚实边界）。
36. 简历上哪个数字最硬？为什么？→ 29 tests/5.4s、TTFT 0.70s、双工具 14.16s：可复现、可追问。
37. 下一迭代做什么？为什么是这个顺序？→ 真实 embedding→评测→压测→Celery；先质量后规模。
38. 这个项目和"调包 RAG"的区别在哪？→ 协议层（tool_calls 流式拼装/自管 session/错误出口/预算收口）都是手写且有测试。
39. 如果网关不支持 tools 字段怎么办？→ 捕获 400 降级为"检索优先+关键词触发工具"的规则模式（可讨论）。
40. 你的 Web UI 和后端怎么联调错误？→ 统一 `{code,message}` + `detail` 兼容字段；错误事件在 SSE 内 `{"type":"error"}`。
