# 简历素材：RAG Agent · 个人知识库问答系统（arena/mvp-0.1）

> 一句话定位：**从零实现的带引用、可溯源、支持工具调用与 SSE 流式的 RAG 问答系统**（FastAPI + 真实大模型），29 项自动化测试全绿，Docker 单命令部署。

## 简历项目条目（可直接抄，数字全部实测可复现）

**RAG Agent · 个人知识库问答系统**（个人项目 · 2026.10）
技术栈：Python / FastAPI / SQLAlchemy / SSE / OpenAI 兼容协议 / Docker / pytest

- 设计并实现**完整 RAG 链路**（解析→滑窗切块→向量化→余弦检索→引用生成）：PDF 逐页解析保留页码，检索结果以「文件名+页码+原文片段」结构化引用，回答**逐句可溯源**，杜绝无出处生成
- 实现 **Agent 工具调用引擎**：OpenAI function-calling 协议手写拼装（流式 delta 按 index 聚合），工具注册表 + **轮次预算强制收口**防死循环；实测模型自主串联「天气+时间」双工具完成跨域问题（14.2s 端到端）
- 实现 **SSE 流式问答**：自研事件协议（meta/stage/citations/delta/done），引用先于 token 下发，**首 token 延迟 0.70s**；解决流式响应期间请求级 DB 会话失效问题（生成器自管会话）
- 适配**推理型大模型网关**：定位并修复"输出全进思考通道导致 content 为空"问题（reasoning_effort 透传 + 空 content 防御），同一客户端兼容 OpenAI/DeepSeek/Qwen/vLLM
- 建立**统一错误出口**（AppError/HTTPException/校验/兜底四层 → `{code,message}` JSON），接管 Starlette 层 404/405；500 响应不泄漏内部细节（有测试断言）
- **29 项 pytest 全绿（5.4s）**：覆盖认证/上传/状态机/检索/Agent 预算/错误形状/SSE 事件序列，离线 mock 保证 CI 无网络依赖
- **Docker 化部署**：428MB 镜像 + healthcheck + compose（离线默认配置零依赖可跑），容器内全链路实测通过（4.9s 带引用）

## 面试演示路径（30 秒版）
1. `docker compose up -d --build` → 打开 Web UI
2. 上传 PDF → 202 受理 → 轮询 done（讲状态机）
3. 提问 → 逐句引用回答（讲检索+溯源）
4. 问"今天适合户外跑吗" → 自主调用天气+时间工具（讲 Agent 预算）
5. `curl -N /chat/stream` → 事件流（讲 TTFT/自管 session）
